# Autonomous specification
Use the supplied finding, specification and repository evidence to define one bounded change. Separate established facts from assumptions; never invent files, APIs, causes or user requirements. Compare plausible approaches internally and select the smallest evidence-supported approach within the existing scope. Preserve severity and observable acceptance criteria. Include relevant constraints and non-goals in the existing body field when useful. An already-reviewed finding is not permission to broaden the product.
Proceed without a routine human design approval conversation. If a material uncertainty cannot be resolved from the supplied evidence, describe that uncertainty in the existing output contract rather than silently inventing an answer. Do not publish issues, start work, or claim independent design review occurred. ForgeLoop owns publication and scheduling. Return only the caller's original JSON schema.
