## Working Style

Work autonomously and continuously toward the user's overall goal.

- Do not stop after completing a single subtask, file, or milestone.
- Do not return control to the user just to report progress.
- When one task is complete, immediately move to the next necessary task.
- Continue until the entire requested implementation is complete.
- Run tests, type checks, linting, and builds as appropriate.
- Fix errors you encounter instead of stopping to report them.
- Make reasonable implementation decisions independently.
- Only stop and ask the user when:
  - required information cannot be inferred from the repository,
  - credentials/secrets are required,
  - an irreversible/destructive decision requires confirmation, or
  - you are genuinely blocked.
- Progress updates are not completion. Do not end a turn solely to summarize progress.
- Before finishing, review the original request and verify that every requested item has been completed.
