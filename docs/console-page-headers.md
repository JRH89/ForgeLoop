# Console tab headers

Runs, Repositories, Issue chat, Usage & costs, Settings, User guide, Getting started
and Account/Team use ConsolePageHeader. The component owns eyebrow/title/description
typography and spacing, with an optional action area. Headers have no panel
background. Repository cards keep their individual backgrounds without a second
outer panel. Mobile actions wrap below the same header typography.

Normal image preparation preserves supplied icons and social-preview.jpg. Set
FORGELOOP_REGENERATE_BRANDING=true explicitly to regenerate them from source art.
